# PalliBazaar - Empowering Rural Commerce

PalliBazaar is an online marketplace bridging rural artisans, farmers, and consumers directly.

## Key Highlights

- **Direct Trade**: Enables rural producers to sell directly without middleman markups.
- **Artisanal Goods**: Showcases traditional handcrafted products with verified heritage.
- **Fair Pricing**: Guarantees transparent pricing structures for both buyers and sellers.
- **Smart Analytics**: Leverages AI market insights to help rural sellers optimize pricing.

## Technology Stack

- **Frontend**: Built with Next.js 16 (App Router), React 19, and TypeScript.
- **Styling**: Styled using Tailwind CSS 4 and smooth animations with Framer Motion.
- **Database**: Powered by MongoDB with Mongoose object data modeling.
- **Authentication**: Secured with Better Auth for robust credential management.
- **Payments**: Integrated with Stripe Checkout for seamless, secure transactions.

## Core Features

- Category-based product discovery and instant search filtering.
- Intuitive shopping cart state management with real-time total calculations.
- Personalized dashboards for managing orders, listings, and customer profiles.
- Seamless light and dark mode toggling using next-themes and responsive layouts.

## Getting Started

Clone the repository using `git clone https://github.com/ruhul2003/PalliBazaar.git`.

Install project dependencies by running `npm install`.

Configure your `.env.local` file with MongoDB and authentication credentials.

Start the development server with `npm run dev` and open `http://localhost:3000`.

Build for production using `npm run build` and launch using `npm run start`.

## Project Structure

The codebase is organized into src/app for routes, src/lib for utilities, and src/models for schemas.
